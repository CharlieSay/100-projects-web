Create an event management platform where organizers can create events, sell tickets, manage attendees, and attendees can discover and register for events.

<h1>Project Checklist</h1>
<ul>
  <li>Create event creation and management interface</li>
  <li>Implement ticket types and pricing</li>
  <li>Build ticket purchase flow</li>
  <li>Add attendee management and check-in</li>
  <li>Create event discovery and search</li>
  <li>Implement email notifications</li>
</ul>
<h2>Bonus Project Checklist Items</h2>
<ul>
  <li>Add QR code ticket generation</li>
  <li>Implement waitlist for sold-out events</li>
  <li>Create event analytics dashboard</li>
  <li>Add social sharing features</li>
  <li>Implement event recommendations</li>
  <li>Add refund and cancellation system</li>
</ul>
