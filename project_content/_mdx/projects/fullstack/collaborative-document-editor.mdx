Create a collaborative document editor where multiple users can edit documents simultaneously with real-time synchronization, conflict resolution, and user presence indicators.

<h1>Project Checklist</h1>
<ul>
  <li>Create document creation and storage</li>
  <li>Implement real-time text editing with WebSockets</li>
  <li>Add operational transformation or CRDT for conflict resolution</li>
  <li>Build user presence indicators</li>
  <li>Create document sharing and permissions</li>
  <li>Implement version history</li>
</ul>
<h2>Bonus Project Checklist Items</h2>
<ul>
  <li>Add rich text formatting (bold, italic, headings)</li>
  <li>Implement comments and suggestions</li>
  <li>Create document templates</li>
  <li>Add export functionality (PDF, DOCX)</li>
  <li>Implement document search</li>
  <li>Add offline editing support</li>
</ul>
