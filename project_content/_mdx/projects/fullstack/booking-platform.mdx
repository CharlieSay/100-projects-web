<h2>Hint/Code snippet to start</h2>
```javascript
// Check availability
async function checkAvailability(resourceId, startDate, endDate) {
  const bookings = await db.bookings.find({
    resourceId,
    startDate: { $lt: endDate },
    endDate: { $gt: startDate },
    status: 'confirmed'
  });
  return bookings.length === 0;
}
```
