Create a social media platform where users can create posts, interact with content, follow other users, and receive real-time notifications.

<h1>Project Checklist</h1>
<ul>
  <li>Implement user registration and profiles</li>
  <li>Create post creation and display system</li>
  <li>Add like, comment, and share functionality</li>
  <li>Build follow/unfollow system</li>
  <li>Create news feed with algorithm</li>
  <li>Implement real-time updates using WebSockets</li>
</ul>
<h2>Bonus Project Checklist Items</h2>
<ul>
  <li>Add image/video upload and processing</li>
  <li>Implement hashtags and mentions</li>
  <li>Create direct messaging system</li>
  <li>Add story/status feature</li>
  <li>Implement content moderation</li>
  <li>Add analytics dashboard for users</li>
</ul>
