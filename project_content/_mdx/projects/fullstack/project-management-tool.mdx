Create a project management application with kanban boards, task assignment, team collaboration, and project tracking capabilities.

<h1>Project Checklist</h1>
<ul>
  <li>Create project and board structure</li>
  <li>Implement task creation with assignees and due dates</li>
  <li>Build kanban board with drag-and-drop</li>
  <li>Add team member management</li>
  <li>Create activity feed and notifications</li>
  <li>Implement task filtering and search</li>
</ul>
<h2>Bonus Project Checklist Items</h2>
<ul>
  <li>Add time tracking for tasks</li>
  <li>Implement Gantt chart view</li>
  <li>Create file attachments for tasks</li>
  <li>Add task dependencies</li>
  <li>Implement project templates</li>
  <li>Add reporting and analytics</li>
</ul>
