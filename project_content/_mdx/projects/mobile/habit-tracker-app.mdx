Create a habit tracking mobile application that helps users build and maintain positive habits with visual progress tracking, streak counters, and daily reminders.

<h1>Project Checklist</h1>
<ul>
  <li>Design habit creation and editing interface</li>
  <li>Implement daily habit check-off system</li>
  <li>Build streak tracking functionality</li>
  <li>Create statistics and progress charts</li>
  <li>Add push notifications for reminders</li>
  <li>Implement local data persistence</li>
</ul>
<h2>Bonus Project Checklist Items</h2>
<ul>
  <li>Add habit categories and tags</li>
  <li>Implement habit templates</li>
  <li>Create social sharing of achievements</li>
  <li>Add habit notes and journaling</li>
  <li>Implement widgets for quick access</li>
  <li>Add dark mode support</li>
</ul>
