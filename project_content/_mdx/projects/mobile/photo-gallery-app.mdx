Create a photo gallery mobile app that organizes photos into albums, applies filters, and provides easy sharing and backup options.

<h1>Project Checklist</h1>
<ul>
  <li>Access device photo library</li>
  <li>Create album organization system</li>
  <li>Build photo grid and detail views</li>
  <li>Implement photo editing (filters, crop, adjust)</li>
  <li>Add photo sharing functionality</li>
  <li>Create search and tagging system</li>
</ul>
<h2>Bonus Project Checklist Items</h2>
<ul>
  <li>Add cloud backup integration</li>
  <li>Implement face recognition for auto-tagging</li>
  <li>Create slideshow mode</li>
  <li>Add photo metadata viewing</li>
  <li>Implement duplicate photo detection</li>
  <li>Add photo printing integration</li>
</ul>
