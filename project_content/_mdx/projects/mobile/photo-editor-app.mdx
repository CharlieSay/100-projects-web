Create a comprehensive photo editing mobile app with filters, adjustments, cropping, text overlays, and creative effects.

<h1>Project Checklist</h1>
<ul>

  <li>Implement crop and rotate functionality</li>
  <li>Add text overlay tool</li>

<h2>Hint/Code snippet to start</h2>
```javascript
// Apply filter
function applyFilter(imageUri, filterType) {
  const filters = {
    vintage: { brightness: 0.9, contrast: 1.1, saturation: 0.8 },
    blackwhite: { saturation: 0 },
    sepia: { sepia: 1 }
  };
  
  return ImageManipulator.manipulateAsync(
    imageUri,
    [{ [filterType]: filters[filterType] }],
    { compress: 0.8, format: ImageManipulator.SaveFormat.JPEG }
  );
}
```
