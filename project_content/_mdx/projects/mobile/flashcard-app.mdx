Create a flashcard mobile app that helps users study with spaced repetition algorithms, multiple choice questions, and progress tracking.

<h1>Project Checklist</h1>
<ul>
  <li>Create flashcard deck management</li>
  <li>Implement card creation with front and back</li>
  <li>Build study mode with card flipping</li>
  <li>Add spaced repetition algorithm</li>
  <li>Create progress tracking and statistics</li>
  <li>Implement card difficulty rating</li>
</ul>
<h2>Bonus Project Checklist Items</h2>
<ul>
  <li>Add image and audio support for cards</li>
  <li>Implement multiple study modes (review, test, cram)</li>
  <li>Create shared deck library</li>
  <li>Add card import/export functionality</li>
  <li>Implement daily study goals</li>
  <li>Add offline mode support</li>
</ul>
