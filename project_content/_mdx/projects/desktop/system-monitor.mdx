Create a desktop system monitor that displays real-time system metrics including CPU usage, memory consumption, disk I/O, and network activity.

<h1>Project Checklist</h1>
<ul>
  <li>Display CPU usage percentage and per-core stats</li>
  <li>Show memory usage (RAM) with visual indicators</li>
  <li>Monitor disk usage and I/O operations</li>
  <li>Display network activity (upload/download speeds)</li>
  <li>Create real-time updating charts</li>
  <li>Add process list with resource usage</li>
</ul>
<h2>Bonus Project Checklist Items</h2>
<ul>
  <li>Add process management (kill, priority)</li>
  <li>Implement historical data logging</li>
  <li>Create alerts for high resource usage</li>
  <li>Add system information display</li>
  <li>Implement export functionality for reports</li>
  <li>Add customizable refresh rates</li>
</ul>

</ul>
