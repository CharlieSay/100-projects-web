Create a desktop file manager application with file browsing, copy/move operations, search functionality, and file preview.

<h1>Project Checklist</h1>
<ul>
  <li>Create file tree/directory browser</li>
  <li>Implement file operations (copy, move, delete, rename)</li>
  <li>Add file search functionality</li>
  <li>Create file preview pane</li>
  <li>Implement file selection (single and multiple)</li>
  <li>Add keyboard shortcuts</li>
</ul>
<h2>Bonus Project Checklist Items</h2>
<ul>
  <li>Add file compression/extraction</li>
  <li>Implement file tagging system</li>
  <li>Create file history/undo functionality</li>
  <li>Add thumbnail generation for images</li>
  <li>Implement file synchronization</li>
  <li>Add cloud storage integration</li>
</ul>
