Build a robust file upload service that handles file validation, storage, and provides APIs for uploading and retrieving files with support for multiple file types.

<h1>Project Checklist</h1>
<ul>
  <li>Create upload endpoint accepting multipart/form-data</li>
  <li>Implement file type and size validation</li>
  <li>Store files securely with unique naming</li>
  <li>Create endpoint to retrieve uploaded files</li>
  <li>Add file metadata storage (name, size, type, upload date)</li>
  <li>Implement file deletion endpoint</li>
</ul>

<h2>Hint/Code snippet to start</h2>
```javascript
const multer = require('multer');
const upload = multer({ 
  dest: 'uploads/',
  limits: { fileSize: 5 * 1024 * 1024 },
  fileFilter: (req, file, cb) => {
    const allowedTypes = /jpeg|jpg|png|gif|pdf/;
    cb(null, allowedTypes.test(file.mimetype));
  }
});

app.post('/upload', upload.single('file'), (req, res) => {
  res.json({ fileId: req.file.filename, url: `/files/${req.file.filename}` });
});
```
