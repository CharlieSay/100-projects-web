Create a search engine API that indexes content, provides full-text search with relevance ranking, and supports advanced filtering and faceted search.

<h1>Project Checklist</h1>
<ul>
  <li>Implement document indexing</li>
  <li>Create search endpoint with query parsing</li>
  <li>Build relevance ranking algorithm</li>
  <li>Add filtering and faceted search</li>
  <li>Implement search suggestions/autocomplete</li>
  <li>Add pagination and result highlighting</li>
</ul>
<h2>Bonus Project Checklist Items</h2>
<ul>
  <li>Integrate Elasticsearch or similar</li>
  <li>Add fuzzy search for typos</li>
  <li>Implement search analytics</li>
  <li>Create search result caching</li>
  <li>Add multi-language support</li>
  <li>Implement search personalization</li>
</ul>
