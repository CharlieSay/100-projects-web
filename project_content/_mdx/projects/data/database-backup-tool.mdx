Create a database backup tool that automatically backs up databases on a schedule, compresses backups, and provides restore functionality.

<h1>Project Checklist</h1>
<ul>
  <li>Implement database connection and backup creation</li>
  <li>Add backup scheduling (daily, weekly, monthly)</li>
  <li>Create backup compression</li>
  <li>Implement backup retention policy</li>
  <li>Add backup verification</li>
  <li>Create restore functionality</li>
</ul>
<h2>Bonus Project Checklist Items</h2>
<ul>
  <li>Add cloud storage integration (S3, Google Cloud)</li>
  <li>Implement incremental backups</li>
  <li>Create backup encryption</li>
  <li>Add email notifications for backup status</li>
  <li>Implement backup monitoring dashboard</li>
  <li>Add support for multiple database types</li>
</ul>
