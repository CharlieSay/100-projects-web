Create a web scraping tool that can extract structured data from websites, handle dynamic content, and export data in various formats.

<h1>Project Checklist</h1>
<ul>
  <li>Implement web page fetching and parsing</li>
  <li>Create CSS selector and XPath support</li>
  <li>Handle JavaScript-rendered content</li>
  <li>Add data extraction and cleaning</li>
  <li>Implement rate limiting and respectful scraping</li>
  <li>Create data export (CSV, JSON, database)</li>
</ul>
<h2>Bonus Project Checklist Items</h2>
<ul>
  <li>Add scheduling for periodic scraping</li>
  <li>Implement proxy rotation</li>
  <li>Create visual scraping interface</li>
  <li>Add data transformation pipeline</li>
  <li>Implement change detection</li>
  <li>Add email alerts for scraped data</li>
</ul>
