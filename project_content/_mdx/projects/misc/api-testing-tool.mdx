Create an API testing tool that allows users to send HTTP requests, validate responses, create test suites, and automate API testing.

<h1>Project Checklist</h1>
<ul>
  <li>Create request builder (method, URL, headers, body)</li>
  <li>Implement request sending and response display</li>
  <li>Add response validation (status codes, JSON schema)</li>
  <li>Create test suite management</li>
  <li>Implement environment variables</li>
  <li>Add request history</li>
</ul>
<h2>Bonus Project Checklist Items</h2>
<ul>
  <li>Add authentication helpers (OAuth, JWT)</li>
  <li>Implement test assertions</li>
  <li>Create test reports</li>
  <li>Add collection import/export</li>
  <li>Implement automated test scheduling</li>
  <li>Add GraphQL support</li>
</ul>
