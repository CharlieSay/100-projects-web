Build a modern chat interface that displays messages in real-time, shows typing indicators, and includes features like message reactions and user status.

<h1>Project Checklist</h1>
<ul>
  <li>Create a chat message list with scrollable container</li>
  <li>Design message input area with send button</li>
  <li>Implement message bubbles with timestamps and sender names</li>
  <li>Add auto-scroll to latest message functionality</li>
  <li>Style messages differently for sent vs received messages</li>
  <li>Add typing indicator when users are typing</li>
</ul>
<h2>Bonus Project Checklist Items</h2>

<h2>Hint/Code snippet to start</h2>
To get started, you can use the following code snippet to structure messages:

```javascript
function addMessage(text, sender, timestamp) {
  const messageDiv = document.createElement('div');
  messageDiv.className = `message ${sender === 'me' ? 'sent' : 'received'}`;
  messageDiv.innerHTML = `
    <div class="message-content">${text}</div>
    <div class="message-time">${formatTime(timestamp)}</div>
  `;
  document.getElementById('chat-messages').appendChild(messageDiv);
  scrollToBottom();
}
```
