Create a weather dashboard that displays current weather conditions, multi-day forecasts, and interactive weather maps using a weather API.

<h1>Project Checklist</h1>
<ul>
  <li>Integrate weather API (OpenWeatherMap, WeatherAPI)</li>
  <li>Display current temperature and conditions</li>
  <li>Create forecast cards for upcoming days</li>
  <li>Add location search functionality</li>
  <li>Display weather icons and descriptions</li>
  <li>Show additional details (humidity, wind speed, pressure)</li>
</ul>
<h2>Bonus Project Checklist Items</h2>
<ul>
  <li>Add hourly forecast view</li>
  <li>Implement weather map integration</li>
  <li>Create weather alerts and notifications</li>
  <li>Add multiple location tracking</li>
  <li>Implement weather history charts</li>
  <li>Add weather comparison between locations</li>
</ul>
