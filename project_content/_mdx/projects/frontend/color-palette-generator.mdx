Create a color palette generator that produces aesthetically pleasing color schemes. Users can generate random palettes, lock specific colors, and export palettes for use in design projects.

<h1>Project Checklist</h1>
<ul>
  <li>Generate random color palettes (5-7 colors)</li>
  <li>Display colors with hex codes and RGB values</li>
  <li>Allow users to copy color codes to clipboard</li>
  <li>Implement color locking to keep specific colors while regenerating others</li>
  <li>Add different palette generation algorithms (complementary, triadic, analogous)</li>
  <li>Create a visual preview area showing colors together</li>
</ul>
<h2>Bonus Project Checklist Items</h2>

<h2>Hint/Code snippet to start</h2>
To get started, you can use the following code snippet to generate colors:

```javascript
function generateRandomColor() {
  return '#' + Math.floor(Math.random()*16777215).toString(16).padStart(6, '0');
}

function generatePalette(count = 5) {
  const palette = [];
  for (let i = 0; i < count; i++) {
    palette.push(generateRandomColor());
  }
  return palette;
}

function generateComplementaryPalette(baseColor) {
  const hsl = hexToHsl(baseColor);
  const complementary = [(hsl[0] + 180) % 360, hsl[1], hsl[2]];
  return [baseColor, hslToHex(complementary)];
}
```
