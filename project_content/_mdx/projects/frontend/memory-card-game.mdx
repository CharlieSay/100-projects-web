A memory card game challenges players to find matching pairs of cards by flipping them over. In this project, you'll create an interactive memory card game with smooth animations, score tracking, and multiple difficulty levels.

<h1>Project Checklist</h1>
<ul>
  <li>Create a grid of cards that can be flipped to reveal images or symbols</li>
  <li>Implement matching logic to detect when two cards match</li>
  <li>Add a timer and move counter to track player performance</li>
  <li>Include visual feedback for matches and mismatches</li>
  <li>Add a reset button to start a new game</li>
</ul>
<h2>Bonus Project Checklist Items</h2>
<ul>
  <li>Implement multiple difficulty levels (4x4, 6x6, 8x8 grids)</li>
  <li>Add a leaderboard to save high scores using localStorage</li>
  <li>Create different card themes (animals, emojis, colors, etc.)</li>
  <li>Add sound effects for card flips and matches</li>
  <li>Implement a hint system that reveals a pair temporarily</li>
</ul>
<h2>Inspiration (Any companies/libraries similar)</h2>
<ul>
  <li>Memory games on mobile app stores</li>
  <li>Brain training applications</li>
</ul>
