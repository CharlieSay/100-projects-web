Create a feature-rich notes application that allows users to create, edit, organize, and search through their notes with support for categories and tags.

<h1>Project Checklist</h1>
<ul>
  <li>Create note editor with title and content fields</li>
  <li>Implement save, edit, and delete functionality</li>
  <li>Display list of all notes with preview</li>
  <li>Add category/tag system for organization</li>
  <li>Implement search to find notes by content or title</li>
  <li>Use localStorage to persist notes</li>
</ul>
<h2>Bonus Project Checklist Items</h2>
<ul>
  <li>Add rich text formatting (bold, italic, lists)</li>
  <li>Implement note pinning/favorites</li>
  <li>Add color coding for visual organization</li>
  <li>Create export functionality (markdown, PDF)</li>
  <li>Add dark mode support</li>
</ul>
