Create a Breakout-style game where players control a paddle to bounce a ball and break bricks, with power-ups and multiple levels.

<h1>Project Checklist</h1>
<ul>
  <li>Create game canvas with paddle and ball</li>
  <li>Implement paddle movement controls</li>
  <li>Build ball physics with collision detection</li>
  <li>Create brick grid with different types</li>
  <li>Add score and lives system</li>
  <li>Implement level progression</li>
</ul>
<h2>Bonus Project Checklist Items</h2>
<ul>
  <li>Add power-ups (multi-ball, paddle size, speed)</li>
  <li>Create multiple level designs</li>
  <li>Implement particle effects</li>
  <li>Add sound effects and background music</li>
  <li>Create level editor</li>
  <li>Add leaderboard system</li>
</ul>
