Create the classic Snake game where players control a snake that grows as it eats food, with increasing speed and score tracking.

<h1>Project Checklist</h1>
<ul>
  <li>Create game canvas and grid system</li>
  <li>Implement snake movement with arrow keys</li>
  <li>Add food generation at random positions</li>
  <li>Implement collision detection (walls and self)</li>
  <li>Create score tracking and display</li>
  <li>Add game over and restart functionality</li>
</ul>
<h2>Bonus Project Checklist Items</h2>
<ul>
  <li>Implement increasing difficulty/speed</li>
  <li>Add high score persistence</li>
  <li>Create different game modes</li>
  <li>Add power-ups and special food</li>
  <li>Implement multiplayer mode</li>
  <li>Add sound effects and music</li>
</ul>
